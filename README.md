# Project Rules

- Must iterate on a **pre-1984 coin-operated arcade game**
- Base game: **Angler Dangler (1982)**
- **Single-player only**
- **No bombs**
- Excluded games: *Galaxian*, *Mappy*, and *Zaxxon*
- Use **directional-pad and single-button controls**
- Include **one mobile-specific mechanic**
- Use an **HD retro sprite-based art style**
- Build with **Unity**
- Publish as an **HTML5/WebGL browser game on itch.io**
- Files must be easy to share without restrictions
- Target a **free-to-play casual and retro audience**
- The game should be **easy to learn but difficult to master**
- Both teams start from the same game; playoff format is to be decided
